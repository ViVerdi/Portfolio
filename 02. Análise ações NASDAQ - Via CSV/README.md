# Sobre o projeto

Este projeto utiliza dados CSV e tratamento dos dados diretamente via Power BI para criação dos gráficos em Power BI.

## COMO ACESSAR

Baixe o arquivo "01. Análise - Extração via CSV.pbix" e utilize o aplicativo do Power BI desktop para abri-lo
Os dados somente poderão ser atualizados caso a fonte de dados do Power BI seja atualizada para um arquivo local do computador.

## MAIS INFORMAÇÕES

O projeto demonstra o tratamento de dados em CSV para ilustrar como é possível transformar um formato tão simples como o CSV (formato comum para extração de informações de sistemas como ERPs e sistemas periféricos) em uma exibição completa e informativa utilizando a plataforma Microsoft.

## FONTE DOS DADOS

O arquivo "HistoricalData_1739577199385.csv" foi extraído do site [Microsoft Corporation Common Stock (MSFT) Historical Quotes](https://www.nasdaq.com/market-activity/stocks/msft/historical)  https://www.nasdaq.com/market-activity/stocks/msft/historical

Para aumentar a eficiência do projeto, o download do arquivo CSV poderia ser automatizado através da linguagem Python utilizando a biblioteca Selenium por exemplo.

## PLANO DE FUNDO DO DASHBOARD

Foi utilizado o PowerPoint para criação dos planos de fundo a fim de manter o uso da plataforma Microsoft em todo o projeto e manter a simplicidade de manutenção do mesmo. O plano de fundo poderia ser criado através do Canva ou outras ferramentas de design porém o PowerPoint costuma ser mais comum nas empresas com plataforma Microsoft, e ferramentas web como o Canvas podem ser bloqueadas para colaboradores por políticas de segurança da companhia.

Este projeto utiliza dados CSV e tratamento dos dados diretamente via Power BI para criação dos gráficos em Power BI.

O projeto demonstra o tratamento de dados em CSV para ilustrar como é possível transformar um formato tão simples como o CSV (formato comum para extração de informações de sistemas como ERPs e sistemas periféricos) em uma exibição completa e informativa utilizando a plataforma Microsoft.

Foi utilizado o PowerPoint para criação dos planos de fundo de forma simplificada a fim de manter o uso da plataforma Microsoft em todo o projeto.
